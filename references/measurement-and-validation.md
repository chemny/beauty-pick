# 测量、评分和验证的可复用规则

## 1. 分层与数据真实性

按“质量观察→候选提取→参数计算→评分→解释→报告”记录来源，不能把其中一层的成功当成全链路成功。

- 候选点、外缘、接触边界、模型估计、衣物表面分别标识，保留缺口与模型分歧。
- 尽可能输出已有信息。一个部位被遮挡，不代表另一侧或另一部位也应关闭。
- 质量阈值优先作为不确定性说明；仍保留解码失败、无效坐标、输入缺失、完全不可见及数值非法等必要保护。安全阈值与审美偏好阈值不能混用。
- 输入放大不等于增加原始细节，补边不等于恢复画面外人体；不能因此虚报原始像素或可见范围。
- 写明测量定义、端点、单位、分母与来源。单幅投影宽不能称为真实围度；不同端点或不同部位来源的比例不能直接等同。
- 没有可测数据时保持原始null；若产品允许默认分，另存默认贡献，不能把默认值写成观察值。规则从应用读取，不擅自补零或补及格分。

## 2. 参数、裁框和模型输入闭环

每次改提取或裁图逻辑，都检查：

1. 原图方向和尺寸是否统一，检测坐标是否正确还原到原图，旧缓存像素是否失效。
2. 裁框是否覆盖全部本次使用的点与线，是否保留上下文；检查左右、缩放、补边和边缘图像。
3. 同高度且来源可说明的左右候选才组成投影宽，单侧不能镜像补齐；断开线段不虚构连接。
4. 原始点、摘要参数、实际裁图及模型收到的数值是否一致；保存输入哈希与版本以便回放。
5. 图示区分直接观察、接触候选和估计；参数摘要直接可读，完整点集可展开或导出。

必要时对真实问题样例做回放；纯几何变换测试不能代替重新检测后的稳定性验证。

## 3. 评分与解释

- 参数辅助只表示参数已作为模型输入，不证明模型按公式计算，也不证明参数准确。
- 纯视觉评分、参数辅助评分、规则计算评分分别记录方法。
- 局部可见范围可以独立评价，不能据此宣称完整身材、背面形态或真实围度。
- 模型解释必须能对应照片或参数。自报高置信度不是验证结果，原始输出中的夸大或越界描述须单列待核对，不能当真值转述。
- 不因单张期望排名改分；不以扩大分差、提高出分率或减少拒绝数证明审美更准。
- 学术测量定义、单篇审美偏好和项目自定分档分开标注，不把工程阈值包装成科学共识。

## 4. 分开统计与验收

统一分母及样本集合，至少区分：

| 指标 | 含义 |
| --- | --- |
| 参数覆盖率 | 至少提取了哪些定义明确的候选参数；外缘和估计可另计 |
| 实际出分率 | 模型/规则确实输出有效观察分；不含默认贡献 |
| 输入方法 | 有分样本中参数辅助、纯视觉、规则计算各多少 |
| 默认贡献 | 缺失项按当前产品规则占用的权重和分值 |
| 质量核对 | 测错部位、衣物误认、范围越界、解释无依据等逐类记录 |

只在已人工核对或独立验证范围内声称准确性。反复调试过的样本属于开发/回归集，不作为未见测试集。

## 5. 版本、缓存、失败与正式接入

- 记录真实模型标识/权重、提示、预处理、参数计算及评分规则版本；行为变化应改变相关引擎/缓存身份。
- 重评失败保留旧报告和失败尝试，明确当前展示是否来自历史。不能用旧分、默认分掩盖模型或服务失败。
- 试验结果迁移必须记录来源与哈希，不虚构新模型调用。正式上传/重评必须执行真正已接入的流程，不导入临时trial目录运行。
- 明确用户冻结的模块、原图和历史记录。批量写入前使用SQLite备份机制或一致性快照，不能假设直接复制运行中的主db文件就足够。
- 事务写入前重新检查任务和报告版本，避免覆盖并发操作。回退只恢复授权范围，保护之后新增的数据。
- 真正调用HTTP上传和force重评验证任务完成、分数可显示、版本正确，核对未修改模块完整报告一致；清理仅限本轮明确创建的测试素材。
- 发现用户并发上传或任务时保留它们，调整校验集合，不用删除新数据来满足固定图库数量断言。

## 6. 沉淀边界

此文只维护流程及校验机制。图片编号、具体错误坐标、临时阈值、样例分数、机器进程、实验目录与每日测试结果留在项目记录。更新技能不自动同步其他Agent副本，不自动修改memory或发布远程。

## 7. 面部参数与审美规则试验

- 人脸定位、身份识别、几何测量与吸引力预测是不同任务。检测或识别模型没有审美训练依据时，不将其输出加入美感权重。
- 比例指标先固定端点、投影轴、分母与适用姿态。沿眼轴处理画面倾斜不等于恢复三维正面；额部网格点不等于发际线，代理点须直说。
- 姿态、遮挡、张口和分辨率属于测量条件，不直接作为长相缺陷扣分。条件降低时分别记录参数可信程度与评分参与方式，不偷偷改变审美含义。
- 定义修正、姿态处理、偏好区间和权重分开做消融对照。保留未改善结果；参数更精确不保证审美排序更合理。
- 以固定参考模型作对照时，相关系数、前列重合和名次差只表示一致性，不能称为人工审美准确率；不为贴近参考排序追调当前样例。
- 新方案未达到预先约定的替换条件时保留现有正式引擎。指标增加、分差变大、定位成功或试验代码完成，都不是切换依据。
