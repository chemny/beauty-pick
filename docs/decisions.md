## D01 产品与范围

## D02 技术栈

状态：已确认方向；依赖兼容性待验证。

React + TypeScript + Vite前端，FastAPI唯一业务后端；Pydantic校验，Pillow/OpenCV图像处理，MediaPipe人脸，c2pa-python来源凭据；SQLite + 本地私有文件。生产本地运行由FastAPI托管前端构建产物。

## D03 模型选择与接入

用户指定：**Codex gpt-6.1-sol，medium**。该选择替代早期Gemini候选推荐。保留原始模型名称与推理配置，不擅自映射成其他公开API型号。

## D04 评分隔离与公式

状态：独立评分已确认方向；整数子分与汇总细则为规划提案。

- 面部权重20/20/25/25/10；摄影25/20/20/20/15，均为实验规则，不声称科学常模。
- 每维度0–10整数。总分=Σ(子分÷10×权重)，四舍五入为整数。必要维度不足时total=null，不重分权重。
- 摄影不读取面部/体态分；面部不读取服装、背景、平台归因等信息作为评分依据。
- 可评状态、观察依据与子分并存，不以检测置信度包装审美可信度。
- M0先给每维度低/中/高描述锚点，并提出明确的可评和稳定性门槛，经审阅后使用。

后果：遮挡照片可能只有部分分数；这是完整表达，不是低分。权重重算与重新调用模型分开。

## D05 来源证据

状态：已确认方向；信任配置与验证器待验证。

证据优先级：可信验证声明/可验证水印 > 未验证元数据 > 视觉/统计弱迹象。签名、资产完整性和签发者信任分开，用户自述不升级为验证结论。冲突保留，平台无证据则为空。

初版不输出未经校准的AI概率或具体平台猜测列表。用明确evidence_level与limitations替代交接草案中含义不明的confidence百分比；若未来引入概率，需要校准数据和误报评测。

参考资料（前期核查，接入时需重查）：

- [C2PA Python官方仓库](https://github.com/contentauth/c2pa-python)：提供读取/验证能力，存在原生依赖。
- [Google SynthID官方说明](https://deepmind.google/models/synthid/)：网页检测入口不等于已验证可程序调用API。

水印插件为条件扩展，不承诺某平台一定可接入。离线验证无法完成的信任/撤销检查应明确限制，不自动联网取远程声明。

## D06 标准化与可评门槛

状态：规划提案。

首版仅方向校正、裁切、等比例缩放，不做曝光校正、五官修改或生成补全。原图保持不变用于凭据验证；工作图仅为评估派生资产。裁剪可由用户调整并使缓存失效。

原因：减少预处理改变肤质、光线和面貌呈现的干扰。像素、角度、模糊和遮挡阈值通过M0样本验证，不当前虚构。

## D07 隐私与成人状态

状态：默认方向已确认；授权记录细则为规划提案。

本地处理默认；第三方主动授权，记录提供商、模块和发送图范围。选择模型不等于授权外发真实照片。多人整图分析需要整图授权，只授权裁脸时不发送整图。

成人状态用户确认，不识别年龄；未确认/未成年禁外貌评分与排行，保留来源和非外貌摄影建议。授权声明不被描述为系统已验证年龄或合法权利。

不默认训练、公开、云同步，不持久化身份嵌入。第三方数据政策须在真正选定调用路径后核查，不能沿用Gemini条款解释Codex。

## D08 生命周期

## D09 任务、费用与失败

状态：规划提案。

SQLite任务状态 + 单进程受限执行器，前端轮询。重启时运行中任务标interrupted，未经确认不重新外发。重试有限且计入预算；不自动换提供商。
