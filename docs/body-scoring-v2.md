# 身材评分 V2：按可见部位评分

2026-10-14 用户确认，替代 V1 的全身比例要求与三项出分门槛。

|指标|权重|
|---|---:|
|可见部位比例|25%|
|上身轮廓|20%|
|腰腹线条|20%|
|臀胯线条|10%|
|腿部线条|10%|
|整体协调|15%|

半身看肩胸腰比例，全身再看上下身；坐姿和截断不自动拒评。贴合衣物能呈现的轮廓可作依据；宽松衣物、遮挡或模糊确实无法判断时，该项为空，不补全。臀胯、腿部各自判断。纯头像及完全看不到身体轮廓时无总分。

有至少一个正权重可评项即可计算：10 × Σ(可评分数 × 原权重) / Σ(可评项原权重)，四舍五入至一位小数。缺项不记零分，不扣分；零分为有效值。不同可见范围的总分不是同条件测量。

规则版本 body-appearance-2.0，提示版本 portrait-body-visible-20261014-4。旧报告保留为历史，不参与新规则排名。颜值与摄影规则不变。界面六项依次显示比例、上身、腰腹、臀胯、腿部、协调，缺项以横线表示。

不以更瘦或更丰满自动加分，不推测真实尺寸或健康，不提出身体改造建议。
